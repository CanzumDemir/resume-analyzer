# Resume Analyzer frontend

This directory contains the Next.js frontend for the AI Resume Analyzer.

Project documentation, architecture, setup instructions, tests, and known
limitations are maintained in the repository's [main README](../README.md).

From this directory, use `npm ci` followed by `npm run dev` for local
development. The frontend expects `NEXT_PUBLIC_API_URL` in `.env.local`; copy
`.env.example` as a starting point.
